# Lakme Makeup Shopping Application

A comprehensive C++ console-based shopping application for Lakme cosmetics, allowing users to browse, select, and purchase makeup products across multiple categories.

## Features
- **Product Categories**: Eye Makeup, Face Makeup, Lip Makeup, Nail Makeup, and Skin Care
- **Interactive Shopping**: Browse products, select quantities, and add to cart
- **Shopping Cart**: View purchased items with category-wise breakdown
- **Billing System**: Automatic subtotal and grand total calculation
- **User Authentication**: Basic login system with password verification
- **Payment Options**: Cash on Delivery and Online Payment
- **Delivery Details**: Collect customer information for order processing

## Technical Details
- Object-Oriented Programming (OOP) concepts
- Inheritance and polymorphism
- Vector-based product management
- Input validation and error handling

## How to Run
```bash
g++ -std=c++11 Shopping_system.cpp -o Shopping_system && ./Shopping_system
